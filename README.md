## 项目概述

开发一款**非商业、离线优先**的 Windows/macOS 桌面高中学习资源软件，面向山东省高中生，同时兼顾全国各地资源。软件提供九大学科知识点讲解、独立试题、完整试卷、组合检索、阅读与双向来源定位、收藏、试题录入及智能 PDF 组卷；**不提供在线做题**。

技术基线：**Tauri 2 + React + TypeScript + Rust + SQLite**；Windows 原生开发、Git 管理、macOS 自动化构建，发布前必须进行 Mac 实际运行验证。

## Windows 功能测试版

知卷 KnowPaper（测试版）提供当前用户 Windows x64 NSIS 安装。0.2.0 和 0.2.1 使用独立的 Preview 数据配置。升级前保存工作并正常退出知卷。默认卸载保留学习资料，重装后继续读取原库。已有 POC 资料可用完整备份恢复显式迁移。

0.2.1 的 GitHub Actions 下载含安装器、校验 Manifest 和构建日志。安装包未签名，使用前可按 Manifest 校验 SHA-256。验收使用的 A 和 B 对应不同本机构建，具体哈希与路径见 DEV-011 交接。

## 内容建设与发布门槛（已决定）

- 九大学科完整知识点分类框架；**300** 个经过审核的完整知识点讲解。
- **2,000** 道独立试题，**100%** 具有答案且答案经过核对；其中 **≥95%** 有完整解析（至少 1,900 道）。
- **100** 份完整试卷，**≥95%** 附有答案（至少 95 份）。
- 资料必须有可追溯来源与足够的**再分发权利依据**；非商业用途并不自动豁免版权。
- 上述目标是**正式 V1.0** 门槛，不妨碍提前发布功能测试版本；现无证据表明这些资源已经制作或授权完成。

## 使用顺序

1. 阅读 `docs/08-decisions.md` 的 DEC-039…041，确认三个关键数据规则已经批准，**不得再重复提问**。
2. 根据 `docs/09-open-issues.md` 继续处理合法资源来源与剩余实施问题，并整体审查 `docs/01-srs.md`。
3. 对 SRS 与技术设计进行最终版本化签核后按 `docs/07-development-plan.md` 进行 `POC-001` 等技术验证；必要的 PoC 准备可提前开始。
4. 每个开发任务必须有：关联需求编号、可运行验收、真实测试输出、Git 提交与 `PROJECT_STATUS.md` 更新。

## 权威性顺序

1. 用户确认后的正式 SRS 与修订决策记录；2. 用户已做出的 38 轮明确选择；3. 本包中经审查的技术设计；4. 示例、建议与演示内容。发生冲突时**不得静默选择**，必须记录并请求确认。

## 不属于 V1.0 的内容

在线答题、强制账号/云同步、AI 自动拆题或 AI 语义搜索、深色主题、复杂独立笔记系统、专业 Word 排版与多窗口 PDF 批注工作台，均未纳入 V1.0。需变更流程才能新增。
