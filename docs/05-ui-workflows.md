# UX — 导航与端到端使用流程（草案）

## 1. 视觉及全局结构

- 固定简洁浅色主题，中文界面，侧边栏导航：**首页、知识库、试题库、试卷库、我的收藏、自定义组卷、资源管理、设置**。
- 首页：突出全局搜索、九大学科入口、最近浏览、常用操作与资源更新摘要。
- 侧边栏可折叠以适配笔记本小屏；保留基本缩放、键盘焦点可视性和必要的对比度；**不引入暗色模式和高度可定制首页**。
- 深色背景不是原始 PDF 试卷的默认查看方式，PDF 保留原貌。

## 2. 首次启动

1. 欢迎页说明离线与本地数据特点，允许跳过可选介绍。
2. 提供默认资源根目录，并允许选择其他盘/目录；已有备份用户可以恢复。
3. 校验/初始化附带资源，不依赖登录或联网，失败显示可操作的错误和日志位置。
4. 进入导航首页，后续启动直接进入首页。

## 3. 知识点 → 试题 → 原始试卷

1. 选择数学 → 函数与导数 → 单调性；显示讲解、例题和易错点。
2. 查看关联试题；选择高级筛选如年份、地区、来源及难度。
3. 在列表/卡片之间切换；侧边预览题干，答案默认折叠。
4. 查看关联原卷，跳至原始 PDF 页码/区域；多小问题显示所属共同材料。
5. 可收藏，或加入组卷篮。

## 4. 试卷导入 → 截题 → 手工编辑 → 检索

1. 导入 PDF 原卷；从文件名规则建议地区/学科/年份，用户确认。
2. 软件内打开 PDF、找到题目并截取区域，或粘贴文字/图片。
3. 新建逻辑题并设置题型、小问、共用材料、答案/解析、知识点与原始来源。
4. 保存时生成稳定 ID 与文件关联；自动草稿保存用于异常恢复。
5. 使用组合筛选找到题目，在原卷和独立详情之间双向跳转。

**边界：** 复杂 DOCX/Office 公式粘贴不保证无损；扫描 PDF 默认不提供 OCR 全文搜索；截图型试题不自动变成结构化文字。

## 5. 自定义组卷 → 答案分离 → 打印

1. 搜索并批量选择多个题目，可按题型分组或手动调整顺序。
2. 对多小问应用依赖校验，不能让题目脱离必需的前置材料。
3. 设置标题、模板、分值、A4 页面边距、作答区域及答案模式。
4. 提供打印预览，提示低分辨率图像、可能断页与超长内容。
5. 生成试题 PDF 与独立答案 PDF，检查编号/题干/图形对应后保存到用户选择的位置。
6. 保存组卷方案以备再次修改；具体引用版本策略待 OID-003。

## 6. 公共资源更新与异常恢复

1. 资源管理 → 导入 `.studyzip`（扩展名待冻结）→ 查看新增/变更/重复数。
2. 校验内容/兼容/空间后确认安装，显示进度与失败原因。
3. 更新后保留收藏和用户覆盖/副本；若发现内容冲突，按既定策略提示。
4. 删除用户题目默认先进入回收站，删除收藏夹不应连带删除原题。
5. 用户可手动备份/恢复完整资源库，并进行 Windows/macOS 迁移。

## 7. 关键错误提示

| 情况 | 推荐操作 |
|---|---|
| 原始 PDF 文件缺失 | 显示缺失资源 ID，提供重新定位/恢复；不直接清理索引 |
| 截图题分辨率不足 | 显示导出质量提示，可更换更清晰来源 |
| 未核对的答案 | 明确展示核对状态，不显示“已核对” |
| 资源包文件损坏 | 导入前阻止并解释具体清单文件 |
| 编辑器意外退出 | 重启后发现草稿，提供恢复或丢弃 |
| 已组卷题目被移入回收站 | 提示被引用关系，恢复后可重新导出 |
