# PACK — 离线资源包协议 v1

知卷使用本地 `.studyzip` 资源包。DEV-009 已验证包读取、公共增量升级、重复和冲突检查、Windows 中断恢复。协议及兼容范围见 [资源包格式 v1](../DEV-009_PACK_FORMAT.md)。

- 应用从 ZIP 预检查、逐成员限额与 SHA-256 开始，在校验内容和引用后显示差异，由用户确认。成员路径只用于查找清单内容。应用最终文件路径由验证过的哈希构造。
- 包协议版本为 1，现有导入器需要 Schema 8 和 RevisionContent v1。应用程序更新与离线资源包升级使用独立版本。
- 同包、同版本、同归档字节报告已安装。同版本不同归档冲突。更高版本追加公共元数据与修订，保留个人数据；降级拒绝。
- 安装器在 SQLite 提交之前持久化操作意图、暂存并无覆盖发布文件。SQLite 内一致提交资源和版本记录。重启可根据持久日志反查提交与清理情况。
- 包内来源、身份和许可是声明。正式发行仍受 OID-004、质量标准及 DEC-039 至 DEC-041 约束。哈希核验仅支持完整性。现行 SRS 保持自身签核流程。
