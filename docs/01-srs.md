# SRS-V1.0 — 软件需求规格说明书（草案）

**项目**：山东高中学习资源平台（暂定名称）  
**版本**：DRAFT-0.2 / 2026-11-10（已纳入 DEC-039…041）  
**状态**：**三项核心数据规则已获批准；SRS 全文仍待最终基线审核；应用尚未开发**  
**依据**：第 1—38 轮需求选择（详见 `08-decisions.md`）

## 1. 目标、用户、边界

### 1.1 产品目标

提供面向山东高中生、兼顾全国各省历年高中考试资源的非商业、离线优先桌面应用。使用者可依高考知识点阅读知识讲解，浏览、查找和整理独立题及完整试卷，保存文件到电脑，组合题目导出可打印 PDF。软件不要求在线答题、账号或持续联网。

### 1.2 目标用户

- 普通高中生：按学科/知识点学习、检索、收藏、导出与打印。
- 资料维护人员：手动编辑知识/试题、导入文件、维护资源包及校对状态。
- 本地设备使用者：备份、迁移及恢复个人数据，无需账号。

### 1.3 术语

- **知识点**：有稳定 ID 的分类或考点实体；可以没有完整讲解，但仍可关联试题。
- **知识讲解**：为知识点提供的结构化正文、方法、例题、易错点等内容，完成后可纳入 300 篇目标。
- **逻辑试题**：可独立识别的题目实体，可含共用材料、小问；正式计数以唯一顶层逻辑题为单位；子问数量另计，同题多出处不重计（DEC-039）。
- **试题出现记录**：一道逻辑试题在某份试卷中的题号、页码及区域坐标，不等于新试题。
- **完整试卷**：一场考试对应的原始整卷实体，可关联多种文件版本、答案及解析。
- **资源包**：包含元数据、结构化题目/知识与附件的离线可导入归档。
- **正式 V1.0**：通过功能、跨平台、资源数量质量及合法分发条件的版本。

### 1.4 明确不做

在线作答/自动判分、强制账号、自动云同步、AI 自动拆卷/智能识题、复杂个人笔记系统、专业自由拖拽 Word 页面排版、深色主题、高度自定义首页及专业 PDF 批注工作台。未来新增必须经变更评估。

## 5. 发布区分与验收原则

- **技术验证程序**：可局部验证技术，不宣称完整功能。
- **功能测试版**：核心流程可实操，允许预装资源未达到正式数量/质量，但应清楚标注为测试版。
- **正式 V1.0**：必须 `FR` 必需项与 `NFR` 发布门槛通过，且 `CNT-001…007` 全部满足。
- 所有“通过”必须来自真实的测试输出、审查记录或许可清单；不能仅由 AI 文本声明。

## 6. 需求变更

采用第 34 轮 **受控变更机制**：修复已承诺功能的缺陷不算新增需求；必要技术变动评估影响后记录；新增功能默认后移至 V1.1/V2.0。每次变更更新决策记录、SRS、测试、Git 提交说明。
